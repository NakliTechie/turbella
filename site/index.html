Remember Winamp? Remember MilkDrop?

Let your coding agent mesmerise you.

Turbella plays your coding agents' tool calls, failures and permission waits through MilkDrop presets, with a gauge for when one is stuck. It runs on your Mac, with no account, no server and no telemetry.

Install View on GitHub v0.1.0 · free and open source · MIT

A visualiser driven by your agent

Every event becomes sound for the picture, though nothing plays aloud. A tool call is a pluck, a failure is a bass hit, thinking is a slow swell and a permission wait is a held note. The turbulence gauge, from 0 calm to 1 stuck, adds noise and wobble as the agent gets stuck. A readout says what each agent is doing and for how long.

The plain record

The timeline shows one lane per agent session. Each tool call is a tick, dark for edits and grey for the rest.

  • A failure is a red spike; the same failure again gets a repeat mark.
  • A permission wait is amber.
  • Thinking is a violet dot, larger for longer.
  • The silence since the last event is shaded while live.

Beside your agents (macOS)

turbella overlay opens a small always-on-top window for each agent session, each with its own picture, gauge and current action. turbella run <agent> runs any terminal agent with its own gauge pinned to the terminal's top row.

Works with the agents you use

  • Claude Code
  • Codex
  • Copilot CLI
  • Cursor
  • Hermes
  • opencode
  • pi
  • omp
  • dsh

Any other app can send events and read the gauge; docs/PLUGINS.md is the contract.

What leaves your machine

Nothing. Events carry tool names, statuses, durations and SHA-256 hashes. Prompts, file contents, tool output, error text and thinking text never leave the hook. The daemon listens on a Unix socket and on 127.0.0.1 only.

Install

Claude Code, from its plugin marketplace:

claude plugin marketplace add NakliTechie/turbella
claude plugin install turbella@turbella

Other agents, from a clone:

# Cursor, opencode, pi, omp: writes the agent's plugin file
turbella install cursor
# Codex, Copilot CLI, Hermes, dsh: prints the steps
turbella install hermes
  • Start a session; the visualiser opens at http://127.0.0.1:7377/viz within 5 seconds of the first hook.
  • On a Mac: turbella overlay for the floating windows, turbella run claude for the strip.
  • macOS and Node 22. Linux and Windows are not supported yet.
